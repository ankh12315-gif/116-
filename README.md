# 当前版本 V11

当前主页面固定有窗，使用配套传感器服务。构建后运行 `npm run serve:local`，访问 http://127.0.0.1:5184/；开发运行 `npx vite`。纯静态服务器不提供新传感器接口。

默认2倍速，正常MOCK无10℃偏差；异常按钮优先匹配同工况后续阶段。温度体场与烟气独立显示。完整说明及限制见 [V11验收](docs/v11/VALIDATION.md) 与 [新版说明书](docs/v11/116配电室网站说明书_V11.docx)。下方保留早期版本资料，涉及旧界面、自动切换与传感器逻辑的描述以V11为准。

# V8：有窗 / 无窗双场景

当前顶部可直接切换场景，真实几何、独立温度/烟气/局部热释放、时间轴和MOCK自动逻辑同步切换。默认保留既有自动演示；新增场景只使用其已完成的高压和低压结果。切换暂停并重新计时，不跨场景回退，传感器可自行输入MOCK温度。

新增文件为定时移除六个构件的版本，包含柜体HOLE；“无窗”沿用上传名称，不代表永久封闭无开口房间。已有16工况和原SPAN/PER_LSB资产不变。两场统一绝对温度色标，点修正不修改空间场。

[完整V8数据审计、实际截图、对比、代码清单和验收](docs/v8/VALIDATION.md)。当前本地预览：http://127.0.0.1:5182/ 。运行V8资源构建时用 `python -X utf8 scripts/build_scene_modes_v8.py`；脚本仅写新派生目录，不执行FDS或旧转换器。

# V4：按红线精简、手动MOCK读数与清晰热量展示

本轮只移除截图划线的人工柜体/功率选择、大面积报警框、专业分析入口；保留未划线的屋顶/透明显示工具。右上角“传感器温度”可输入MOCK读数并应用，或恢复自动读数。手动读数在本次页面会话内生效，刷新恢复代码默认。未触发时用于演示阈值判断，触发后仅修正监测点曲线，不抬高整个空间温度。

默认温度展示新增独立的高度3m完整原始SF帧层：16工况、73切片、每片1001帧（约1.8秒），Float32无损导出。旧量化资产及科研能力仍保留；下文旧101帧/18秒及SPAN/PER_LSB参数描述的是原资产，不是新增默认展示层。色标使用高对比连续温度色，温度不会被新配色改变；俯视热量、真实热点和40℃等温线帮助看清变化。40℃仅是显示阈值，等温线不是燃烧边界。

# 116配电室火灾三维可视化 · V3 自动演示

当前版本在原 React / TypeScript / Three.js 工程中实现。打开页面后自动监测 MOCK 柜位通道、定位起火位置、匹配真实 FDS 工况并播放温度切片，无人工柜体或功率选择，也没有后台页面。

默认：HV-01 / 70MW；演示温度达到120℃并持续1秒后触发（约演示绝对时间6秒）。这些阈值仅为演示参数，没有设备/材料物理判据依据。高压源输入是约1秒短时释放，剩余时间展示传播/冷却；HRR输出仍严格读取真实曲线，不推断成因。

## 运行

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5181
```

当前生产预览：http://127.0.0.1:5182/ 。关闭本轮预览终端后，可用 `npx vite preview --host 127.0.0.1 --port 5182` 重新启动。

拖动模型旋转、滚轮缩放，右键拖动平移。自动播放后可暂停、拖动时间轴、修改速度；点击“未来温度”再点+10/+30/+60秒。点击时间显示可精确跳转，不是常驻科研参数面板。未来模式暂停当前播放，明确区分当前时刻、目标时刻与实际温度场帧时刻。

## 内部配置与接入

- `src/config/fireSimulation.ts`：默认柜位、高压40/70/100/140MW档、MOCK触发序列、演示阈值、持续判定、监测点、偏差上限、修正开关及结果路径。`scenarioForCabinet`明确映射8个低压和8个高压工况。
- `src/simulation/AutomaticFire.tsx`：自动监测→匹配→FDS播放；固定监测点修正结果另行记录于 `monitorRecords`，不会写入FDS资产。
- `src/simulation/sensorSource.ts`：替换 `SensorSource.read` 可接入传感器读数。必须带测点、工况及演示绝对时间戳；实际系统须另建立Unix时间与仿真起点的标定。
- `src/simulation/monitorCorrection.ts`：点时间插值、错时/错点/错工况/缺测拒绝、±20℃有界偏差修正。没有整个空间的外推。

模拟绝对时钟从0开始。`FDS relative = sensor absolute − fireOriginAbsoluteS`。前期触发通道在配置的起火位置，固定梁下点是独立的单点修正通道，不能凭这一个固定点自动反演柜位。播放暂停、跳转时MOCK跟随演示时钟；它不是独立运行的真实传感器。

暂定监测点为FDS `(11.5,-12,4.5)` 梁下气相位置。16工况均有同坐标原始SF覆盖，低压响应弱，尚不能认定全房间最优。MOCK=原始点曲线+10℃，仅验证程序管线；修正后同样本残差为0不代表物理预测准确。未来修正只是冻结当前点偏差的实验性推算；未来三维场仍显示原始FDS结果。
